## About Me

I'm a software developer based in the Philippines, specializing in building end-to-end applications — from crafting responsive, user-friendly interfaces to engineering backend APIs and database architectures. My core focus areas are **Software Development**, **System Design**, and **UI/UX Prototyping**.

I care about writing clean, practical code and shipping projects that hold up in real use, whether that's a small business platform, a school organization site, or a local government portal.

## Development Approach

**Plan → Design → Build → Integrate → Test → Deploy → Improve**

I start by understanding the problem before writing code — mapping out structure, designing practical interfaces, and building reusable components. From there I connect APIs and databases, test functionality, deploy, and keep improving based on real usage.
